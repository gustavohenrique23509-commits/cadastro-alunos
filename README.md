# Sistema de Cadastro de Alunos

## Descrição
Projeto desenvolvido em Phyton para a disciplina de Git a Github

##Funcionalidades
- Cadastrar alunos
- Listar alunos
- Buscar alunos pelo nome

## Tecnologias utilizadas
- Python
- Git
- Github

## Objetivo
Aprender a utilizar commits, branches, issues e pull requests.
